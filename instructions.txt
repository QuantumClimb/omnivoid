PYTHON SERVER INSTRUCTIONS
==========================

To start the Python server:

1. Open terminal/command prompt in the project directory
2. Run: python -m http.server 8000
3. Or run: python -m http.server 3000 (if port 8000 is busy)

Local URL: http://localhost:8000
Alternative URL: http://localhost:3000

To stop the server: Press Ctrl+C in the terminal

Note: Make sure you're in the project root directory (K:\F DRIVE\OMNIVOID\Bruno\LABS) when running the command.
